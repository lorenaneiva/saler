## Como interpretar esta documentação

Código, migrations e testes são a evidência do comportamento implementado. O PDF registra intenção/requisitos e não comprova implementação. Quando este conjunto divergir, confira a implementação atual e os testes mais recentes antes de mudar o sistema; registre a divergência em vez de apagar a distinção. Os documentos foram revisados contra o código e o histórico disponíveis em 26/11/2026.
